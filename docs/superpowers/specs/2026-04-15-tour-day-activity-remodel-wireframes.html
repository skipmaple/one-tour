2 · 确认宪法（新 Tour 的第一步）

spec §宪法的机器表示；tours.constitution 建 Tour 时深拷贝 Constitution::DEFAULTS。此屏允许用户在开始规划前审阅并调整宪法。规划过程中也可随时从 Planner 顶部菜单 📜 再次进入修宪。自顶向下：先定规则 → 再列候选 → 再规划
《本程宪法》 PATCH /tours/:id （constitution 字段）
💡 这份宪法是给你这次旅行的基础规则。大多数情况下默认值就够用 —— 可以直接点 "使用默认 →" 开始。
如果情况特殊（老人小孩、长距离赶路、特殊饮食），往下调整相应参数。

关键约束 （99% 的人只看这 3 条就够）

四、违反处理（只读；详见 Screen 9）

· 硬约束违反 → 红色 banner，可 "承认" 写入 constraint_overrides 永久静音
· 软违反 → 黄色提示，单次 dismiss
· 宪法 不 阻止保存 —— 只提示，不拦截（soft-validation 策略）

用户改动过任一参数后：主 CTA 的文案自动变成 "保存修改并开始 →"，默认按钮变成 "放弃修改用默认"。 触发 PATCH /tours/:id/constitution → 跳转到 Screen 3 空白起点
点击 "↺ 恢复默认" 后的二次确认（仅当用户改过参数）防止误点丢失修改

恢复宪法到默认值？

你已修改了 3 个参数（每天最多驾驶：6 小时 → 7 小时；每天核心景点：2 → 3；特色餐厅：2 → 3 家）。
恢复默认会 丢弃这些修改，无法撤回。

用户未修改任何参数时，按钮禁用；点击直接无反应，不弹 confirm。
规划中再次进入修宪的入口 Planner 顶部菜单 📜

规划中任何时候都可以点 Planner 顶部 📜 图标返回此屏修宪。修宪后：

  • 所有现有 activity 立即重跑一轮 Tour::ConstitutionCheck
  • 新的违反显示为黄/红 banner；旧的 constraint_overrides 依然有效
  • 修宪不回溯历史 —— 只影响当前与后续校验
AI 同样可以提议修宪 AITools::UpdateConstitution

例如用户说 "这次允许山路驾驶到 5 小时"，AI 调用 update_constitution(tour_id, {max_mountain_road_minutes: 300})，前端收到 tool_call_result 后刷新宪法展示并重跑 ConstitutionCheck。

自顶向下的三步：① 定宪法（此屏） · ② 列候选行（Screen 3-4） · ③ 规划日程（Screen 5）

拖拽的失败 / 警告态 drop validation
A. 拖到已超时的 Day（实时警告）

用户还在拖拽、悬停到 D3 上方时，不等落下，D3 列立即变红边框 + 显示浮动警告：

⚠ D3 已 6h30 驾驶，再加这条会到 8h（超过每天 7h 上限）

用户可以选择：松开 → banner 变红硬违反；或继续拖走到别处 → 警告消失

B. 拖到 buffer day（提示确认）

buffer_day 是"预留空白"，拖进去会给一个确认弹层：

把 夏塔古道 放到 D6（机动日）会让 D6 不再是 buffer。
[取消] [继续放入]

按"继续放入" → D6 自动从 buffer_day=true 切回 false，顶部自动升起软提示"整程 0 机动日"

C. 后端落库失败（回滚）

前端乐观更新：拖拽 → 立即落位 → 发 PATCH /activities/:id/position

若请求失败（422 / 5xx / 网络）：

  • 活动 自动回到原 Day / 原 position
  • 顶部 toast 标红："拖拽未保存 重试"
  • 重试成功 → toast 变绿 "已保存"；再失败 → toast 保持红色不消失
D. 拖到一半按 Esc / 丢到画布空白处（取消）

按 Esc：原卡片回到起始位置（含 Backlog 内的原位置），被拖动占位瞬间恢复，地图上拖拽中的蓝 pin 变回灰 backlog pin。
丢到 Days 列之外的空白：同上。
实现上靠 dragend event + drop-zone 校验。

四种失败态共同原则：不静默失败。A/B 是预防式（落下前阻止），C/D 是恢复式（落下后回滚 or 取消）。
落位后的 Toast 全局 undo 机制
已把 赛里木湖 加到 D2 第 2 位 撤销 4 秒后消失

每次用户 / AI 的变更都显示一个浮 toast（右下或底部居中），5 秒倒计时消失。期间点 "撤销" 可回滚上一步。覆盖：

  • 拖拽 move_activity / 编辑 update_activity / 删除 delete_activity / 添加 add_activity
  • AI 一次 tool-call 序列视为一组（撤销会撤整组，如"AI 批量加了 20 个 POI" 一次撤销全部）
  • 修宪 update_constitution / 承认违反 acknowledge_violation —— 也能撤销，但 toast 保留 10 秒
实现建议：前端维护一个 undo stack（最多 10 条，老的自动丢）；只做 "撤销上一步"，不做完整 redo。是 spec 边界里标 YAGNI 的 undo/redo 的 "80% 用例" 简化版。
落位后 D2 右下角会自动跳到：驾驶 150 min · 一等×1 · 二等×0

12 · 端到端用户流程（把 spec 的产品目标串起来）

对应 spec "产品目标" 章节。自顶向下：宪法 → 列候选 → 规划。Step 0 是宪法确认，不可跳过
Step 0 · 定宪法（见 Screen 2）

新建 Tour 后先确认宪法，再进入规划。宪法是本程的硬/弹性规则来源。

  • 深拷贝 Constitution::DEFAULTS
  • 用户可调任一参数（max_daily_driving_minutes 等）
  • 规划中随时 📜 图标再修订
Step 1 · 罗列（见 Screen 3）

确认宪法后（Screen 2），新建 Tour 的 Backlog 是空的。两个入口把想去的点塞进来：

  • 手动 "+ 加一个" → 打开 Screen 6 的编辑面板
  • 自然语言对 AI 说 "把伊犁必去的 10 个景点加进来"
  • AI 批量调用 search_poi + add_activity（见 Screen 8 的 tool-call 流）
Step 2 · 地图自动展示

每个 activity 的 (lat, lng) 自动在地图上呈现灰 pin（未分配）。

  • 无手动操作
  • 视图切换：按天着色 / 全部 / 仅 backlog
Step 3 · 拖入 Day

用户把 backlog 卡片拖到 D1 / D2 / D3… 或 AI 帮做。

  • 前端乐观更新 position
  • 后端 PATCH /activities/:id/position
Step 4 · 连线 + Dn 标签

地图上实时画 D1→D2→D3… 的路径折线，pin 标 "D2"。

  • 折线几何来自 AMAP（前端懒请求）
  • 不缓存于 DB
Step 5 · 年表化详情

点某一 Day 进入 Screen 11 的时间轴视图。富 UI 展示。

贯穿 · 宪法校验

任意变更后自动跑 Tour::ConstitutionCheck，顶部 banner 实时更新。

  • hard / soft 违反分色
  • 承认后静音（需二次确认，见 Screen 9）
贯穿 · Undo toast

每次变更（用户 / AI）显示 5 秒 toast，可撤销。见 Screen 5 末尾。

  • AI 批量操作视为一组撤销
  • 前端 undo stack 上限 10，老的丢弃

边缘场景（原型没画独立屏，这里明示行为）

失败态
  • AI tool-call 异常：Chat 气泡显红，给"重试"按钮；活动未落库
  • AMAP 拉坐标失败：search_poi 返回"暂无匹配"，引导手工输入 lat/lng
  • 拖拽失败（后端 422）：活动自动回到原位，顶部 toast 标红 "拖拽未保存，请重试"
  • 地图加载失败：占位图 + "重新加载" 按钮；不阻塞 Backlog / Days 编辑
  • 实时连线渲染失败：静默降级为直线，不报错
离开 Planner 的出口
  • ← 返回 Tour 列表：顶部面包屑，自动保存草稿
  • 归档：tours.archived = true，仍可查看但不参与推荐
  • 删除：需打入 "DELETE" 二次确认，联级删除 days / activities / conversation
  • 成员退出：非 author 的 editor / reader 可点"离开本程"，自毁 tour_memberships
分享（YAGNI · 本 spec 不做）
  • 导出 markdown：从 Tour/Day/Activity 渲染出类似老 Guidebook 的可打印路书
  • 只读分享链接：非成员 token-based 只读访问
  • 打印友好视图：整程单页打印，手机离线可查
  • 导出 GPX：给车载导航
产品上下阶段考虑；本 spec 仅显性标记
其他明确不做的（见 spec "范围边界"）
  • POI 收藏夹 / 跨 tour 复用（Location 表）
  • Tour 模板（宪法模板留了字段但只有 default 一个）
  • 宪法硬阻止保存 —— 只做 soft-validation
  • 完整 undo/redo stack —— 只做 5 秒 toast 撤销上一步
  • 老 guidebook 数据迁移
  • 移动端 / 响应式 —— 桌面 ≥ 1280px 首要
