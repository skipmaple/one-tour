# One-Tour 吉祥物设计概念

> **目标**：为路书（One-Tour）设计承载产品 DNA 的吉祥物 IP，用于 App icon、AI 助手头像、空状态插画与后期周边。
>
> **结论**：**小鹿（Xiǎo Lù）—— 梅花鹿幼鹿**。利用「鹿/路」普通话同音 + 鹿身斑点 ≈ 地图标记点的双重设计杠杆。
>
> **后续**：本文档是概念阶段产出，落地需要插画稿、style guide、icon 替换 PR、AI 头像接入四步（详见末尾路线图）。

## TL;DR

| 项 | 决策 |
|---|---|
| **形象** | 梅花鹿（Sika Deer）幼鹿，双足拟人化造型 |
| **中文名** | 小鹿（Xiǎo Lù），与"小路"完全同音 |
| **英文名** | Lulu / Sika |
| **品牌主色** | Mantine teal-6（青绿） + 茶褐 + 月白，走中国传统色系 |
| **核心视觉杠杆** | 身侧斑点设计为 map pin 形态，可独立成图形系统 |
| **首要应用** | App icon（替换 Rails 默认红圆）+ AI 助手头像（`ChatPanel.jsx`） |

## Context（为什么要做这件事）

One-Tour（路书）当前没有真正的品牌视觉资产——`public/icon.svg` / `public/icon.png` 是 Rails 默认占位（红圆），不承载任何叙事，也不构成色彩约束。这意味着我们其实拥有**完全的视觉自由**，可以从零为产品建立一个能"长大"的吉祥物 IP。

产品本身已经具备了清晰的人格底色——**面向中文用户的协作式旅行规划器**，不是冷冰冰的工具，也不是浮夸的旅游营销 App。在 ToB 协作工具普遍冷感、ToC 旅行 App 普遍俗艳的赛道里，一个有性格的吉祥物可以同时解决三个问题：

1. **图标差异化**：从"Rails 默认红圆"升级为可记忆的形象，撑住 favicon、桌面图标、OG 图、应用商店截图等所有品牌触点
2. **AI 助手人格化载体**：当前 `app/javascript/components/planner/ChatPanel.jsx` 的 AI 助手没有面孔，吉祥物可以成为助手头像，让"问路书"这件事有了对象感
3. **周边可延展性**：贴纸、徽章、文创为后期社区运营和小规模 merch 留出空间

设计目标不是"做个可爱形象"，而是**让吉祥物承载产品 DNA**：协作、靠谱、懂路、有中国味、不油腻。

## 品牌 DNA（设计约束输入）

从代码与文案中提炼出的**必须尊重**的输入：

| 维度 | 现状 | 对吉祥物的约束 |
|---|---|---|
| 产品名 | 路书（lù shū），即古代实用旅行手册 | 形象需有"知识/手册/向导"感，不是纯萌宠 |
| 域名 | `tour.skipmaple.com`，"skip + maple" | 隐含跳跃感与枫叶意象，可作彩蛋 |
| 字体 | LXGW WenKai（霞鹜文楷，清雅中文衬线） | 形象需匹配"雅而不古板"的气质 |
| 色彩 | **无品牌色**（现有红圆是 Rails 默认占位，不算品牌资产）；UI 仅有 Mantine teal 点缀 | 色彩可自由设计，建议走中国传统色系而非赛道俗色 |
| 用户 | 中文用户、群体出行 | 文化扎根中国，避免硬蹭"adventure buddy"西式语境 |
| 功能气质 | 行程严谨 + 费用精算 + AI 闲聊 | 形象需"靠谱"为底，"亲切"为面，禁止傻憨 |
| 已有元素 | Tabler 线性图标 + Mantine UI | 吉祥物造型需能与简洁线性 UI 共存，不抢戏 |

## 推荐方案：小鹿（Xiǎo Lù）—— 梅花鹿幼鹿

### 为什么是梅花鹿

经过多方向比选（详见末尾备选清单），**梅花鹿**是唯一同时命中以下**全部六个**品牌锚点的载体——其中前两点是几乎天作之合的设计杠杆，单独任一项都足以构成强推荐理由：

#### 杠杆 1：「鹿 / 路」完美同音

- **小鹿（xiǎo lù）= 小路（xiǎo lù）**——产品名"路书"的灵魂字"路"，与"鹿"是普通话完全同音字
- 这意味着吉祥物的名字本身就是一句产品 slogan：「跟着小鹿走，走遍每条路」
- 中文吉祥物命名能踩中这种同音梗的概率极低（多数靠生造叠词），这是**先天的品牌语言资产**
- 海外场景仍可叫 `Lulu` / `Sika`，命名一鱼两吃

#### 杠杆 2：身上的斑点 = 地图标记点

- 梅花鹿身侧的白色斑点排列与地图上的 location pin / waypoint 高度神似
- 这是吉祥物**自带的视觉故事**——不是硬塞道具，而是花纹本身就是产品功能的隐喻
- 在 icon、贴纸、loading 动画里，斑点可以**动态点亮 / 串成路线**，形成可演绎的图形语言
- 这一点是其他任何动物都无法替代的视觉杠杆

#### 其他强支撑

- **中国本土物种 + 文化深度**：梅花鹿原产中国，《诗经·小雅》"呦呦鹿鸣"是关于宴客同游的经典意象，与"群体出行"主题在中国古典文脉里就有连接；又有"逐鹿"的探索意味
- **群居动物**：鹿群（herd）天然契合"协作式多人行程"
- **气质匹配 LXGW 文楷**：鹿在中国视觉传统里是清雅、灵动的象征，与霞鹜文楷的清秀气质同调
- **赛道空白**：旅行类 App 吉祥物常见企鹅、狐狸、地图针、纸飞机；鹿几乎是处女地（仅滴露/鹿牌等无关品牌占用）
- **周边友好**：苗条体型 + 标志性斑点 + 优雅鹿角，在徽章、贴纸、毛绒、印章四类周边都极具表现力

### 角色设定

- **名字**：**小鹿（Xiǎo Lù）**
  - 与"小路"完全同音，是路书最自然的拟人化身
  - 英文：**Lulu** / **Sika**（保留中文音节）
- **身份**：路书馆的"小向导"。读过很多旅行手册，性格不是冷冰冰的导览员，更像"陪你一起翻行程的朋友"
- **性格关键词**：靠谱（不是萌呆）/ 好奇（爱标记新地点）/ 利落（行程整理强迫症）/ 暖（群体出行不掉队）
- **声音感**：温和清亮的少年/少女音，不卖萌

### 视觉规格（交付给设计师的具象要求）

**形态**：

- 双足直立的**幼鹿**拟人化造型（幼鹿斑点最明显且最合规——成年公鹿斑点会淡化）
- 头身比约 1 : 1.3（轻微 Q 版，但保留五官比例的成年感，避免低龄化）
- **特征锚点**：
  - 头顶**两支萌芽期的小鹿茸**（毛茸短角，不要鹿王那种夸张大角，避免霸气感）
  - 身侧 **5–7 颗白色斑点**沿背脊节奏排列，**斑点形状必须是"圆角矩形"或"圆角水滴形"**——明确暗示 map pin 形态
  - 大眼睛 + 黑色湿润鼻头 + 短尾
  - 蹄子精炼，避免拟人化到穿鞋

**配色**（建议走中国传统色系，HEX 待设计师 token 化）：

| 部位 | 色彩描述 | 命名建议 |
|---|---|---|
| 主体毛色 | 温暖茶褐色（warm tea brown） | 茶褐 / `#B07A50` 系 |
| 腹部/下颌 | 米白（cream） | 月白 / `#F5EDE0` 系 |
| 斑点 | 纯净白 + 轻微金边 | 米白带金（提升精致感） |
| 鹿茸/蹄/鼻 | 深栗棕（deep walnut） | 沉稳收边 |
| 主点缀色 | **Mantine teal-6 青绿** | 用于眼神光、围巾、罗盘——确立产品品牌色 |

> **关键决策**：把 Mantine teal 正式提升为**品牌主色**。当前 UI 已经在用，吉祥物配色与 UI 同源，不会割裂。

**标志性道具**（pick one or stack 用于不同场景）：

1. **小路书**：腋下夹一本浅色封面、有书签飘出的小册子（首选，承载产品名）
2. **青绿色围巾 / 罗盘项链**：青绿色丝带或小罗盘，作为品牌主色的视觉锚
3. **枫叶徽章**：肩头/腰包上一片小枫叶（"skipmaple" 彩蛋）

**禁止项**：

- 不要拟人化到穿全套衣服（会变成 IP 玩具，丢失动物本体魅力）
- 不要加眼镜/工牌/西装（不是企业吉祥物）
- 不要做"愤怒/卖萌/搞怪"夸张表情（违反"靠谱为底"基调）
- 不要画成大角公鹿（变成霸气向，与产品调性矛盾）
- 不要把斑点画成爱心/星星（破坏 map pin 的隐喻锚点）

## 标志性视觉语言：斑点路线（Spotted Route）

吉祥物之外，从小鹿身上的斑点提炼出一套**可复用的图形系统**，让品牌延伸不只依赖具象形象：

- **Loading 动画**：5 颗白点依次亮起，像在地图上点亮路径
- **空状态 / 分隔线**：用 5–7 颗 teal 圆角点替代普通线条
- **OG 图背景纹理**：斑点散布构成轻量底纹
- **周边纹样**：贴纸、行李牌可只用斑点 pattern，不出现完整角色

这让吉祥物从一个"画"升级为一套**视觉语法**——是 IP 资产可持续的关键。

## 应用场景规划

### 1. App Icon（最高优先级）

- **方案 A（推荐）**：圆形构图，米白底 + 小鹿头部正面 + 一颗高亮 teal 斑点作为视觉焦点
- **方案 B（极简）**：抽象出"鹿角 + 一颗斑点"构成的字符形 icon，用于 favicon 极小尺寸
- **路径**：替换 `public/icon.svg`、`public/icon.png`；现有 `<link rel="apple-touch-icon">` 与 favicon 已在 `application.html.erb` 第 19–21 行声明，需要的是替换为新资源并按需追加多尺寸
- **同时新增**：OG 图（当前完全缺失）、PWA maskable icon

### 2. AI 助手头像（高价值）

- 在 `app/javascript/components/planner/ChatPanel.jsx` 的助手消息气泡前展示小鹿的小头像
- 助手对话从"AI 回了我"变为"小鹿告诉我"，认知锚点从抽象工具变为具体伙伴

### 3. 空状态插画（中价值）

- 当前缺空状态设计的页面：无行程的 Tour、无成员的协作页、无费用的结算页
- 小鹿的不同动作（举地图、坐着翻账本、招手等同伴）填补空状态，比 Tabler 图标更有温度

### 4. 周边 Roadmap（远期，不阻塞当前）

- **Tier 1 数字周边（零成本）**：微信表情包、Telegram sticker pack、Notion 模板封面
- **Tier 2 实物周边（用户激励）**：贴纸、行李牌、明信片、小徽章（斑点 pattern 单独可用）
- **Tier 3 长线 IP**：毛绒挂件、"路书"主题文创笔记本

## 备选方案（已评估，不推荐为主方案）

| 方案 | 优点 | 否决原因 |
|---|---|---|
| 红熊猫（小路路） | 中国本土、毛色温暖、握取道具自然、赛道空白 | 没有"鹿/路"的命名同音红利；身体花纹无法形成 map pin 视觉隐喻 |
| 小驼（骆驼，丝绸之路意象） | 中国旅行文化深厚，天然群居 | 形象偏古典，与现代 App UI 气质割裂；造型笨重难做 icon |
| 小燕（燕子/雨燕） | 群飞迁徙呼应群体出行，诗意 | 鸟类吉祥物泛滥（Twitter/Duolingo 等），辨识度难做；爪子无法持物 |
| 拟人化路书（书精灵） | 直白对应产品名 | 静物拟人难做表情和动作，周边延展性差 |
| 水豚 | 当下流行、自带"chill 群居"标签 | 非中国本土、与产品"靠谱精算"调性矛盾，纯蹭热度 |
| 小狐狸 | 灵巧、暖色系 | 已被 Firefox / 一众旅行 App 占领，无差异化 |

## 落地路线图

本文档是**概念阶段产出**，落地需要以下后续动作：

1. **形象稿（Week 1）**：找插画师（或用 Midjourney/Stable Diffusion 起稿）出 3 个姿态草图——站立举书 / 坐姿翻地图 / 招手等同伴；同时确认斑点位置规律
2. **Style guide（Week 2）**：成稿后产出色板 token、表情库（最少 6 表情：默认/开心/好奇/思考/抱歉/睡觉）、姿态库、斑点图形系统规范
3. **Icon 替换 PR（Week 2 末）**：替换 `public/icon.svg`、`public/icon.png`，同步替换现有 favicon / `apple-touch-icon` 资源（已在 layout 中引用），新增 OG / PWA maskable，并在 `app/views/layouts/application.html.erb` 按需追加多尺寸引用
4. **AI 助手头像接入（Week 3）**：在 `ChatPanel.jsx` 助手消息组件中接入头像
5. **可量化验证（上线 +30 天）**：跟踪 OG 图分享点击率、App 安装转化率、AI 助手使用率作为对照指标
